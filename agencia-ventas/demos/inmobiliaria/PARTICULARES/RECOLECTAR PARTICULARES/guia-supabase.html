Guía de configuración — Supabase

Seguí estos 5 pasos y en 15 minutos los avisos van a aparecer automáticamente en el sitio.

~15 minutos 100% gratis Sin conocimiento técnico
1

Crear cuenta gratuita en Supabase

Entrá a supabase.com y hacé clic en "Start your project". Podés registrarte con tu cuenta de GitHub o con email.

El plan gratis incluye base de datos, almacenamiento de fotos y API. No te van a pedir tarjeta de crédito.
2

Crear un nuevo proyecto

  1. Hacé clic en "New Project"
  2. Nombre del proyecto: grupo-inversa-particulares
  3. Elegí una contraseña para la base de datos (guardala en un lugar seguro)
  4. Región: South America (São Paulo) — la más cerca a San Juan
  5. Hacé clic en "Create new project"

Esperá unos segundos mientras Supabase crea el proyecto.

3

Crear la tabla de avisos (SQL)

  1. En el menú izquierdo hacé clic en "SQL Editor"
  2. Hacé clic en "New query"
  3. Copiá y pegá todo el siguiente código:
-- Tabla de avisos create table public.listings ( id uuid default gen_random_uuid() primary key, nombre text not null, telefono text not null, categoria text not null, operacion text not null, titulo text not null, precio text, moneda text default 'ARS', zona text not null, descripcion text not null, fotos text[] default '{}', status text default 'pendiente', created_at timestamptz default now() ); -- Seguridad alter table public.listings enable row level security; -- Cualquiera puede VER los avisos aprobados create policy "ver_aprobados" on public.listings for select using ( status = 'aprobado' ); -- Cualquiera puede PUBLICAR un aviso nuevo create policy "insertar_aviso" on public.listings for insert with check ( true ); -- Índices para velocidad create index on public.listings (status); create index on public.listings (categoria); create index on public.listings (created_at desc);
  1. Hacé clic en "Run" (botón verde)
  2. Deberías ver el mensaje "Success. No rows returned"
También podés abrir el archivo supabase-setup.sql que está en la carpeta del proyecto y pegar todo su contenido.
4

Crear el bucket de fotos (Storage)

  1. En el menú izquierdo hacé clic en "Storage"
  2. Hacé clic en "New bucket"
  3. Nombre: listing-photos
  4. Tildá la opción "Public bucket"
  5. Hacé clic en "Save"
  6. Ahora hacé clic en el bucket que se creó (listing-photos)
  7. Andá a la pestaña "Policies"
  8. Hacé clic en "New policy" > "For full customization"
  9. Policy name: upload_publico | Operation: INSERT | Expression: true
  10. Guardá
Sin este paso las fotos de los usuarios no se van a poder subir.
5

Conectar el sitio con Supabase

Necesitás copiar dos valores de tu proyecto y pegarlos en el index.html.

¿Dónde están esos valores?

  1. En el menú de Supabase andá a "Settings" → "API"
  2. Copiá el valor de "Project URL"
  3. Copiá el valor de "anon public" (en la sección "Project API Keys")

¿Dónde los pego?

Abrí el archivo index.html con cualquier editor de texto (Bloc de Notas, VS Code, etc.) y buscá estas dos líneas al inicio del script (al final del archivo):

const SUPABASE_URL = 'TU_SUPABASE_URL'; const SUPABASE_ANON_KEY = 'TU_SUPABASE_ANON_KEY';

Reemplazá TU_SUPABASE_URL con tu Project URL y TU_SUPABASE_ANON_KEY con tu clave anon. Ejemplo:

const SUPABASE_URL = 'https://abcdefghij.supabase.co'; const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';

Guardá el archivo.

La clave anon es pública por diseño. Podés usarla en el HTML sin problema. Nunca uses la clave service_role en el front-end.
✓

¿Cómo aprobás los avisos que llegan?

Cada vez que alguien publica en tu sitio:

  1. Te llega un mensaje por WhatsApp con todos los datos del aviso
  2. Entrás a supabase.com → tu proyecto → "Table Editor" → tabla "listings"
  3. Buscás el aviso nuevo (va a tener status = pendiente)
  4. Hacés doble clic en el campo status y lo cambiás a aprobado
  5. Hacés clic en "Save"

Al instante ese aviso aparece en el sitio con su tarjeta, fotos y botón de WhatsApp.

Más adelante podemos agregar un panel de administración dentro del mismo sitio para que puedas aprobar avisos con un clic, sin entrar a Supabase.

¡Listo para funcionar!

Una vez que completaste los 5 pasos, tu sitio va a recibir avisos reales, subir las fotos y mostrarlas en tarjetas automáticamente.
