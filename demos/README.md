# Demos Standalone por Nicho

Esta carpeta contiene demos individuales para cada nicho de negocio, listos para enviar a clientes potenciales.

## Estructura

```
demos/
├── inmobiliaria-standalone/     ← Demo inmobiliaria individual
├── peluqueria-standalone/       ← Demo peluquería individual
├── ropa-standalone/             ← Demo tienda de ropa individual
├── gimnasio-standalone/         ← Demo gimnasio individual
├── veterinaria-standalone/      ← Demo veterinaria individual
├── taller-standalone/           ← Demo taller mecánico individual
├── estetica-standalone/         ← Demo estética/nails individual
├── odontologia-standalone/      ← Demo odontología individual
├── gastronomia-standalone/      ← Demo gastronomía/viandas individual
└── servicios-hogar-standalone/  ← Demo servicios del hogar individual
```

## Características de cada demo

- **Landing page completa** con hero específico del nicho
- **Catálogo/demo interactivo** según el tipo de negocio
- **Sección de beneficios** adaptada al rubro
- **Planes de precios** (Presencia / Ventas Automáticas / Pro)
- **Formulario de contacto** o botón WhatsApp
- **Diseño responsive** y profesional
- **Listo para deployar** en Netlify

## Uso

1. Entrá a la carpeta del nicho correspondiente
2. Subí el contenido a Netlify (drag & drop)
3. Compartí el link con el cliente potencial
4. El cliente ve exactamente cómo quedaría su negocio digitalizado

## Personalización

Cada demo puede personalizarse con:
- Nombre del negocio del cliente
- Colores de marca
- Productos/servicios específicos
- Número de WhatsApp
- Logo
